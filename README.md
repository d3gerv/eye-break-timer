# eye-break-timer
It counts down 20 minutes of focus time, then switches to a 20-second “look 20 feet away” break. After the break it starts the next 20 minutes. You can pause or reset it, and it keeps a count of breaks taken today. A soft chime and an optional desktop notification tell you when to switch. It follows your device’s light or dark mode.

The tab needs to stay open for the timer to keep running. Notifications only show if you allow them in your browser.
